岁岁春欢，红果上映 79集共 ，九月中旬上映
简介：前世，沈嘉岁与陆云铮惨死别院，沈家惨遭构陷满门覆灭。她重生于陆云铮提亲之日，却发现对方亦携记忆归来，当众弃她迎娶养女顾惜枝。心死斩断旧情的她，决心护下沈家、揭穿伪善面目。朝堂夺嫡风波四起，她结识大理寺少卿江浔结为同盟，携手破解宅斗权谋、深挖陈年旧案。她步步为营逆转宿命，洗刷家族冤屈，与良人相守圆满。
**第一集｜前世惨死，重回提亲之日**

**主要人物**

- **沈嘉岁**：定国将军府大小姐，小名“岁岁”。
- **陆云铮**：昭勇将军府大公子；前世为沈嘉岁的丈夫。
- **沈征胜**：定国将军，沈嘉岁之父。
- **纪宛**：定国将军夫人，沈嘉岁之母。
- **白芨**：沈嘉岁的丫鬟。
- **顾惜枝**：本集仅在对白中被提及，未出场。

**1—1｜00:00—00:23｜外景·京西别院庭院·夜／前世**

**出场人物：** 沈嘉岁、陆云铮。

**画面与动作：**

夜色笼罩别院，圆月悬在屋脊上方。

庭院地面散落着兵器和倾倒的灯笼。沈嘉岁与陆云铮倒在血泊中，两人衣衫染血，面上、嘴角留有血迹。

沈嘉岁身上插着长刃；陆云铮上身亦有刺入物。两人睁着眼睛，身体没有明显动作。

**旁白：**

“大胜归朝，名扬盛朝的少将军陆云铮，与结发妻子沈嘉岁惨死于京西别院。”

“大理寺定案，二人争执互杀，同归于尽。”

“一世纠葛，终成惨烈闹剧。”

**镜头变化：**

庭院全景与月亮、屋脊的建立镜头 → 地面血泊与两人身体 → 沈嘉岁面部特写 → 转移焦点至陆云铮 → 两人伤势及同框俯拍 → 拉开至庭院全景 → 黑场。

**剧情节点：**

先展示前世死亡结局，交代夫妻关系及官府定案。

**情节说明：**

旁白转述官府对两人争执互杀的结论。

**1—2｜00:24—00:46｜外景·沈府回廊·日／重生后**

**出场人物：** 沈嘉岁、白芨。

**画面与动作：**

沈嘉岁穿浅色衣裙，站在回廊中，神情恍惚。她看着眼前熟悉的环境，眼神中带着惊疑。

白芨快步靠近，笑着连声唤她。

沈嘉岁缓缓转头，望向白芨，像是在确认对方的存在。

**对白：**

白芨：
“小姐，小姐……您怎么站在这里发呆？”

沈嘉岁：
“白芨？”

白芨：
“奴婢在呢。”

“小姐，您这是怎么了？”

“莫非是反悔了，不想去看热闹了？”

沈嘉岁：
“去哪？”

**镜头变化：**

沈嘉岁侧面中近景，叠加人物介绍 → 面部近景停留 → 白芨进入画面 → 双人中景 → 两人正反打。

**剧情节点：**

由前世死亡切入重生后的日常，以白芨的正常反应反衬沈嘉岁的震惊。

**1—3｜00:47—01:08｜外景·沈府回廊·日**

**出场人物：** 沈嘉岁、白芨。

**画面与动作：**

白芨兴致勃勃地说起提亲之事。

沈嘉岁听着，眼神逐渐凝住，脸色变得难看。她意识到自己回到了过去。

白芨察觉异常，伸手扶住她的手臂，担忧地询问。

**对白：**

白芨：
“小姐您忘了，今日陆公子上门提亲。”

“这会定然正在府里永安堂候着呢。”

“您一早还念叨着要去瞧瞧，怎么一转眼就糊涂了？”

**内心独白——沈嘉岁：**

“不可能。”

“我明明和陆云铮在别苑同归于尽，怎么会重回沈府？”

“难道我重生了？”

**对白：**

白芨：
“小姐，你脸色怎么这么难看？”

“可是身子不舒服？”

**镜头变化：**

白芨说话近景 → 双人镜头 → 沈嘉岁面部逐步收紧 → 短暂晃动、模糊的转接画面 → 沈嘉岁眼神特写 → 白芨扶住她的双人镜头。

**剧情节点：**

确认重生时间点：陆云铮登门提亲当天。

**1—5｜01:18—01:32｜内景·沈府永安堂·日**

**出场人物：** 陆云铮、沈征胜、纪宛、沈嘉岁、白芨。

**画面与动作：**

沈征胜与纪宛端坐堂上，陆云铮站在堂中，向二人陈述来意。

沈嘉岁奔至堂外，在门口听见陆云铮的求娶对象并不是自己。她停住脚步，目光冷下来。

白芨随后赶到。

**对白：**

陆云铮：
“沈伯父，沈伯母。”

“云铮今日登门，只求迎娶府上顾惜枝顾姑娘为妻。”

“晚辈倾心府上顾惜枝顾姑娘多年，今日专程登门，恳请伯父伯母允这门婚事。”

**镜头变化：**

沈嘉岁来到门口的背面镜头 → 门外逆光面部近景 → 陆云铮正面中近景及人物介绍 → 沈氏夫妇同框及人物介绍 → 从陆云铮背后望向门口的镜头。

**剧情节点：**

提亲对象发生改变：陆云铮要求迎娶顾惜枝，直接冲击原有婚约。

**1—6｜01:32—01:47｜内景·永安堂门口及堂内·日**

**出场人物：** 沈嘉岁、纪宛、陆云铮、沈征胜、白芨。

**画面与动作：**

沈嘉岁走进堂内。纪宛起身迎向女儿，将她抱在怀中。

沈嘉岁紧靠母亲，眼中含泪；但她越过母亲肩头看向陆云铮时，眼神警惕而清醒。

陆云铮转头看她。两人隔着一段距离对视。

**对白：**

纪宛：
“岁岁……我的岁岁。”

**镜头变化：**

沈嘉岁走入的中景 → 纪宛迎上去 → 母女拥抱 → 沈嘉岁从母亲肩头望出的特写 → 陆云铮与沈征胜的反应镜头 → 沈嘉岁眼神近景。

**剧情节点：**

重逢父母的情绪与面对前世丈夫的戒备叠加，表现沈嘉岁内外不同的状态。

**1—7｜01:47—01:59｜内景·永安堂·日**

**出场人物：** 沈嘉岁、陆云铮、纪宛、沈征胜、白芨。

**画面与动作：**

陆云铮审视沈嘉岁，神情起疑。

纪宛仍将女儿护在怀中，转向陆云铮，严厉质问。

沈嘉岁听着母亲的话，目光始终停留在陆云铮身上。

**内心独白——陆云铮：**

“沈嘉岁怎么来了？”

“莫非她也重生了？”

**对白——纪宛：**

“陆云铮，当年若非你父亲再三登门、百般央求，我们才应下这门婚约。”

“今日你毁约，要置我岁岁于何地？”

**内心独白——沈嘉岁：**

“果然，他也重生了。”

**镜头变化：**

陆云铮侧面特写 → 母亲护住女儿的中景 → 纪宛斥责与陆云铮反应交替 → 沈嘉岁含泪而冷静的特写。

**集尾节点：**

沈嘉岁确认陆云铮也带着前世记忆归来。剧情在“双重生”的认知上停住。

**第二集｜当堂退婚，反击开始**

**出场人物：** 沈嘉岁、陆云铮、沈征胜、纪宛、白芨及堂内侍女。顾惜枝仍未正式出场。

**2—1｜00:00—00:19｜内景·永安堂·日**

**画面与动作：**

陆云铮紧皱眉头，观察沈嘉岁。

沈嘉岁依偎在母亲身旁，低头握着手，看上去柔弱、伤心。

陆云铮看着她的反应，逐渐打消疑虑。

**内心独白——陆云铮：**

“沈嘉岁若也重生了，定然早已提剑与我对质。”

“绝不会这般柔弱黯然。”

“是我多虑了。”

**镜头变化：**

陆云铮审视的特写 ↔ 沈嘉岁依偎母亲、垂眼的近景 → 回到陆云铮面部，停留其判断过程。

**剧情节点：**

陆云铮误判沈嘉岁没有重生。观众知道的事情，比陆云铮更多。

**2—2｜00:19—00:35｜内景·永安堂·日**

**画面与动作：**

沈征胜愤然起身，抬手作出拍击动作，怒视陆云铮。

陆云铮站在堂中，没有退让。沈嘉岁仍在母亲身边，观察他。

**对白——沈征胜：**

“陆云铮！”

“你竟敢如此负我岁岁，是欺我沈家无人成？”

**内心独白——陆云铮：**

“惜枝才是真心爱我、懂我之人。”

“前世我顾虑太多，最终两两惨死，满盘皆输。”

“如今我已知结局，绝不可重蹈覆辙。”

**镜头变化：**

沈征胜起身中景 → 陆云铮正面镜头，母女处于后景 → 陆云铮侧面中景 → 面部特写 → 母女反应镜头。

**剧情节点：**

父亲公开维护女儿；陆云铮的内心独白交代他改变婚事的主观理由。

**2—3｜00:35—00:54｜内景·永安堂·日**

**画面与动作：**

沈征胜压着怒意，质问陆云铮。

陆云铮整理衣襟、站直，直言自己只爱顾惜枝。

沈征胜听后露出短暂冷笑，随即更加愤怒。纪宛搂住沈嘉岁的肩，安抚她。

**对白：**

沈征胜：
“退了大的，又迎娶小的。”

“陆公子，你好大的野心啊！”

陆云铮：
“沈伯父，晚辈直言。”

“我对岁岁自始至终只有兄妹情谊，从无半分儿女情长。”

“我心悦之人，唯有顾惜枝姑娘。”

沈征胜：
“好个不知廉耻的东西！”

“你若对岁岁只是兄妹之情，为何不提解除婚约？”

“偏偏等到提亲之日！”

**镜头变化：**

沈征胜面部近景 → 从其肩后拍陆云铮的中景 → 陆云铮整理衣襟 → 沈征胜冷笑、斥责的近景 → 陆云铮反应 → 母亲安抚女儿的双人镜头。

**剧情节点：**

冲突由“爱谁”转向“为何在提亲当天毁约”，突出对沈嘉岁及沈家体面的伤害。

**2—4｜00:54—01:00｜内景·永安堂·日**

**画面与动作：**

沈嘉岁抬眼，神情从受伤转为决断。

她离开母亲身边，走到陆云铮面前。低机位透过前景木构，拍摄她的裙摆和两人的站位。

陆云铮向她道歉，并提出补偿。

沈嘉岁抬手，一掌打在他脸上。陆云铮的头被打偏。

**对白——陆云铮：**

“岁岁，是我对不起你。”

“你要什么补偿，我都可以应允。”

**镜头变化：**

沈嘉岁抬眼近景 → 裙摆、脚步及两人站位的低机位镜头 → 沈嘉岁眼神特写 → 掌掴动作与陆云铮偏头反应。

**剧情节点：**

沈嘉岁从旁观转为主动行动，拒绝用“补偿”轻轻带过毁约。

**2—5｜01:00—01:12｜内景·永安堂·日**

**画面与动作：**

陆云铮脸上出现红痕，抬手捂脸，震惊地看着沈嘉岁。

沈嘉岁直视他，语气坚定，当众宣布婚约作罢。

陆云铮放下手，情绪转为恼怒，仍坚持迎娶顾惜枝。

**对白：**

沈嘉岁：
“陆云铮，你确实对不起我。”

“沈陆两家的亲事就此作罢。”

“今日之后，定国将军府自当广而告之——”

“陆家大公子品行不端，不堪为沈家之婿。”

陆云铮：
“随你在外面任意诋毁我。”

“我一定要娶惜枝！”

**镜头变化：**

陆云铮被打后的近景 → 两人对峙中景 → 反打陆云铮捂脸 → 沈嘉岁宣告退婚 → 陆云铮带红痕的面部特写。

**剧情节点：**

沈嘉岁正式切断婚约，并明确以陆云铮失德作为退婚理由。

**画面与动作：**

沈嘉岁没有继续争吵，反而冷静下来，提出让顾惜枝亲自到场。

她转身望向母亲，言辞平稳，眼神中带着笃定。

**对白——沈嘉岁：**

“也好断了陆云铮的妄念。”

**2—7｜01:21—01:35｜内景·永安堂·日**

**画面与动作：**

纪宛认可女儿的提议，仍相信顾惜枝温柔守礼，与沈嘉岁姐妹情深。

她转头吩咐侍女去请二小姐，又提醒她们说话委婉。

白芨低头应下。

**对白——纪宛：**

“也好。惜枝性子温柔纯粹，恪守礼调，与女儿姐妹情深。”

“白霜，将二小姐请来永安堂。”

“白芨，你也去。”

“将此件事告知二小姐时，记得言语委婉些，莫要吓到她了。”

白芨：
“是。”

纪宛与陆云铮同框 → 纪宛吩咐侍女的正面近景 → 沈嘉岁侧面反应 → 白芨低头应答。

**剧情节点：**

母亲对顾惜枝的信任，与沈嘉岁的警惕形成反差，为下一步对质积蓄张力。

**2—8｜01:35—01:43｜内景·永安堂·日**

**画面与动作：**

沈氏夫妇回到堂上座位。沈嘉岁站在堂中，陆云铮在侧。

沈嘉岁缓缓侧头，眼神冷定。门外阳光照在她脸侧，镜头逐渐逼近她的眼睛。

**内心独白——沈嘉岁：**

“上一世，我的未婚夫和好姐妹，联手害我沈家满门。”

“这一世，我势必要当场戳穿，让你们付出该有的代价。”

堂内人物关系全景 → 沈嘉岁逆光侧面近景 → 面部特写 → 眼神特写 → 画面渐暗。

**集尾节点：**

明确女主的复仇动机，并以“顾惜枝即将到场、真相将被揭开”作为下一集悬念。

**片尾：**
