**第一集｜《爱上错误的人》**  

**人物**

- Claire：女主，也是主要旁白叙述者。
- Ethan：Claire从小认识的朋友。
- Adrian：Ethan的哥哥，Claire喜欢的人。
- Vanessa：Claire的室友，Ethan喜欢的人。

**场景1｜00:00—00:20｜外景·草地／公园·日**

**人物：** Ethan、Claire、三名欺凌者。

**动作与表演：**

Ethan倒在草地上，几名男子围住他，其中有人按住他的身体。他脸上已有擦伤，蜷身护住自己。

Claire穿条纹上衣、牛仔背带短裤，手里拿着薯片袋。她看向被围住的Ethan，神情逐渐坚定，把薯片袋丢下，向几人冲过去。

她冲到跟前后倒地、蜷缩。Ethan伸手抱住蓝衣男子的腿，试图阻拦，随后也被甩开。几名男子居高临下地看着两人。

**对白／字幕：**

Claire：
“别碰他！”
【原文：Hands off him!】

蓝衣欺凌者：
“真是一对废物。”
【原文：What a pair of losers.】

**镜头变化：**

Ethan被按在地上的俯拍近景 → Claire腿部、薯片袋和面部的低机位镜头 → Ethan带伤面部特写 → Claire迎面冲来的正面镜头 → 倒地及阻拦动作的快速切换 → 欺凌者俯视两人的中景。

**剧情节点：**

开场直接呈现欺凌冲突。Claire主动保护Ethan，两人却一起受伤，为两人的相互支持关系建立起点。

**场景2｜00:20—00:43｜外景·草地及步道·日，五年前**

**人物：** Claire、Ethan、Adrian、Vanessa；离开的欺凌者。

**动作与表演：**

欺凌者离开。Ethan蹲下扶Claire起来，让她把手搭在自己肩上，搀扶她往前走。

Adrian从后方走来，站到两人身旁。Claire抬眼望向他，随后低头，显出羞涩。

Vanessa出现在前方，笑着招呼。众人转头，Ethan看见她后露出笑容。

**对白／旁白：**

Claire旁白：
“五年前，我身高五英尺三英寸，体重一百七十六磅。”

“而Ethan身高六英尺，体重却只有一百一十九磅。”

“我们站在一起，就像一个保龄球和一根牙签。”

“相比之下，Ethan的哥哥Adrian英俊又健壮。”

“我和他们一起长大。”

“后来，我喜欢上了Adrian。”

招呼声，结合随后切出的画面，应为Vanessa：
“Claire！”

Claire旁白：
“Ethan则喜欢上了我的室友Vanessa。”

**镜头变化：**

欺凌者离去的较宽镜头 → Ethan扶Claire起身的近景 → 两人相互搀扶的中景 → Adrian进入画面 → Ethan、Claire的面部近景 → Vanessa正面镜头 → Ethan微笑特写。

**剧情节点：**

交代四人关系：Claire喜欢哥哥Adrian，Ethan喜欢Claire的室友Vanessa。旁白同时确立两位主角对自身体形的认识。

---

**场景3｜00:43—00:52｜外景·篮球场围网内外·日，那个夏天**

**人物：** Claire、Adrian、篮球场同伴。

**动作与表演：**

Claire站在铁丝网外，望着场内打球的Adrian，起初带着期待和笑意。

Adrian拿着篮球，与同伴说笑。听到他的评价后，Claire脸上的笑容消失，隔着铁丝网怔住。

**对白／旁白：**

Claire旁白：
“那个夏天，我偶然听到Adrian打篮球时说的话。”

Adrian：
“我绝不可能和一个胖女孩约会。”

“跟她一起走在外面，我成什么样子了？”

【对应英文：I could never date a fat girl. / What would I look like walking around with her?】

**镜头变化：**

Claire隔网观看的近景 → 隔着围网拍摄的球场中远景 → Adrian与同伴说笑的中近景 → Claire失落的面部特写。

**剧情节点：**

Claire听见喜欢的人排斥自己的体形，后续减重行为由此获得明确动因。

**场景4｜00:52—01:05｜内外景·临街店铺／咖啡馆门口·日，同年夏天**

**人物：** Ethan、Vanessa、与Vanessa谈话的女子。

**动作与表演：**

Ethan走近店门，面带笑容，准备进入。

店内，Vanessa坐着与另一名女子聊天，用手势强调自己的择偶要求。

Ethan听到她的话，笑容逐渐消失，低头看向自己，表情受挫。

**对白／旁白：**

Claire旁白：
“同一个夏天，Ethan也偶然听到了Vanessa和她最好的朋友聊天。”

Vanessa：
“我喜欢能让我有安全感的男人。”

“如果他胳膊腿都那么细，我怎么依靠他？”

【对应英文：I like guys who make me feel safe. / If he is all skinny arms and legs, how am I supposed to rely on him?】

**镜头变化：**

从门内望向街道的Ethan全身镜头 → Vanessa说话近景 → Ethan带笑靠近 → 店内谈话镜头与Ethan表情特写交替 → Ethan低头的中景。

**剧情节点：**

Ethan同样因暗恋对象的体形偏好受到打击，与Claire形成平行处境。

**场景5｜01:05—01:26｜内景·健身房·时间未明，那个秋天及训练期间**

**人物：** Claire、Ethan、女教练、男教练。

**动作与表演：**

Claire在跑步机上持续跑步，双手抓着扶手，汗湿、喘息，明显疲惫。

女教练靠近劝阻，Claire仍坚持。

另一边，Ethan躺在器械下反复推举，表情吃力。男教练俯身劝他休息，他也不肯停。

最后切到两名教练站在一起交谈的画面。

**对白／旁白：**

Claire旁白：
“于是，那个秋天，健身房里出现了两个疯狂的人。”

女教练：
“慢一点，你的身体受不了这样。”

Claire：
“不行，我必须在他毕业之前瘦下来。”

男教练：
“你需要休息一下。”

Ethan：
“不行，我得在她毕业之前练出些肌肉。”

Claire旁白：
“我们互相监督，也互相告状。”

**镜头变化：**

跑步机上的腿部、手部特写 → 跑步机与后方推举器械的同框镜头 → Claire和女教练双人镜头 → Claire疲惫近景 → Ethan推举中景及面部近景 → 男教练俯身劝说 → 两位教练同框。

**剧情节点：**

两人都开始按照暗恋对象的偏好改变自己，并形成互相监督的关系。

**场景6｜01:26—01:35｜内景·电脑房／住宅另一处·夜及时间未明**

**人物：** Claire、Ethan。

**动作与表演：**

蓝紫色灯光下，Ethan戴耳机打游戏。Claire站在他身后，随后拿着拔出的线，露出得意的笑。Ethan回头看她。

另一段画面中，Claire正在吃炸鸡。Ethan站在门口举起手机拍她，闪光灯亮起。

**旁白：**

Claire：
“如果他通宵打游戏，我就拔掉他的网线。”

“如果我偷吃一口炸鸡，他就会拍照，发给我的私人教练。”

**镜头变化：**

Ethan和游戏屏幕侧面镜头 → Claire拔线后与Ethan的反应镜头 → Claire吃炸鸡的面部、食物近景 → 门口Ethan举手机拍照的镜头。

**剧情节点：**

用两段生活片段具体呈现“互相监督、互相告状”，同时展现两人的熟悉程度。

**场景7｜01:35—01:51｜外景·街道／内景·镜前及房门口·日／时间未明，五年后**

**人物：** Claire、Ethan。

**动作与表演：**

Claire沿街走来，先呈现穿背带短裤时的形象。前景人物遮挡画面后，她变为身形纤细、穿蓝色格纹上衣的样子，微笑继续走。

Ethan站在镜前，画面通过遮挡转场，呈现他从瘦削到肩背健壮的变化。

Claire来到房门口，兴奋地对Ethan说起平安夜的电影约会。她说话时带着笑，身体前倾；Ethan看着她，随后微笑回应她的情绪。

“我从一百七十六磅减到九十八磅。”

Claire：
“我和你哥哥平安夜要一起去看电影！”

“我们把自己变成了暗恋对象希望我们成为的样子。”

街头行走镜头 → 前景遮挡完成形象变化 → 镜中Ethan的身体及倒影 → 遮挡转场呈现增肌后的形象 → 房门口双人中景 → Ethan反应近景。

**剧情节点：**

五年改变完成。Claire满怀期待地宣布约会，两人的付出似乎即将得到回应。
